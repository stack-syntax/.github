## 👋 About

**Stack Syntax** is a developer-first learning project. We share short, practical tips on Instagram ([@stack.syntax](https://instagram.com/stack.syntax)), and every tip you see on screen lives here in **full detail**: complete code, cheatsheets, roadmaps and curated resources.

A Reel gives you the idea in 15 seconds. This organization gives you everything behind it, so you can copy it, run it, break it and learn from it.

**What we believe**
- 🎯 **Practical over theoretical.** Every example is small, runnable and useful at work.
- ☕ **Java deserves modern tooling.** You can build AI apps in Java without switching to Python.
- 🧩 **One concept per example.** Short, focused and easy to reuse.
- 🆓 **Free and open.** Everything here is MIT licensed.

## 🚀 How to use these repos

**1. Clone a repo**
```bash
git clone https://github.com/stack-syntax/<repo-name>.git
cd <repo-name>
```

**2. Open the example folder** you saw in the Reel and read its `README.md`.

**3. Run it.** Most examples need only:

| Requirement | Version |
|---|---|
| JDK | 21 or newer |
| Maven | 3.9 or newer |
| IDE | IntelliJ IDEA (any edition) |

**4. Use API keys safely.** AI examples read keys from environment variables. **Never commit API keys.** Local-model alternatives (for example Ollama) are documented where they're supported.

> ⚠️ Spring AI and the AI ecosystem move fast. If a build fails, check the version in `pom.xml` against the official docs for that library.
