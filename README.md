# Stack Syntax

Code, cheatsheets and roadmaps behind every Reel on Instagram **[@stack.syntax](https://instagram.com/stack.syntax)**.

Java, Spring Boot, Spring AI, LangChain4j, AI dev tools and productivity workflows. Everything shown on screen is here in full, so you can copy it, run it and learn from it.

## Repo map

| Folder | What's inside |
|---|---|
| [`reels/`](reels/) | One folder per Reel: full code, notes, run instructions |
| [`cheatsheets/`](cheatsheets/) | Quick-reference sheets (shortcuts, annotations, etc.) |
| [`roadmaps/`](roadmaps/) | Learning roadmaps for Java, Spring and AI engineering |
| [`templates/`](templates/) | Template used to document every new Reel |

## Requirements

- JDK 21+ (records need 16+, but 21 is the current LTS baseline for these projects)
- Maven 3.9+
- IntelliJ IDEA (any edition)

## How to use

```bash
git clone https://github.com/<your-username>/stack-syntax.git
cd stack-syntax/reels/002-java-records
```

Each Reel folder has its own `README.md` with exact run steps.
